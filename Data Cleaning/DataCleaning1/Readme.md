# Data Cleaning with Pandas

A beginner-level data cleaning project using Python and Pandas.

## Dataset
A deliberately messy employee dataset containing:
- Missing values
- Duplicate records
- Invalid ages
- Invalid salaries
- Inconsistent gender values
- Inconsistent capitalization
- Multiple date formats
- Invalid email data

## Cleaning Operations
- Missing value handling
- Mean and mode imputation
- Duplicate detection
- Data type conversion
- Date standardization
- String standardization
- Invalid value correction
- Index resetting

## Technologies
- Python
- Pandas
- Jupyter Notebook
